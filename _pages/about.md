## 这个博客是什么

一个放技术笔记的地方。不定期更新，想到啥写啥 —— 主要是给自己留个能搜的记录。

## 写哪些方向

- **逆向工程** —— APK / so 层静态与动态分析、JNI、混淆与加固的对抗思路
- **协议与流量** —— 手机端抓包、TLS 与 WebSocket 分析、API 逆向
- **自动化与工具链** —— 把重复的手工操作写成脚本，以及围绕 MCP 的工具开发

## 关于本站

用 Jekyll 搭在 GitHub Pages 上，主题是 [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/)，
全站纯静态、零后端。文章都用 Markdown 写。
